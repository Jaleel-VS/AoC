# Advent of Code, Rust Practice

author: Jaleel van Staden
start date: 15/11/2026

## Daily layout

Keep each day in one file: `YEAR/src/bin/yYEARdDD.rs`.
Use `parse`, `part1`, and `part2` functions; `main` reads the input and prints both answers.
Helpers stay in the same file when useful.

Run from the year's directory, for example:

```sh
cd 2016
cargo run --bin y2016d01
```

Puzzle inputs live in the year's ignored `inputs/` directory.
